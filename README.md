## Anchor

**What if the answer sounds right, but the number is wrong?**

Anchor checks numbers, dates, and named entities in generated answers
against retrieved source chunks. It returns sentence-level findings
and suggests corrections for detected mismatches.

It's a focused verifier, not a guarantee of factual correctness.
Claims without extractable values remain outside its current scope.

[Explore Anchor →](https://github.com/Sujal-Kandi/Anchor-)

## Blog Writer

**A first draft isn't the finished product.**

A writing workflow that separates planning, web research, fact
extraction, drafting, revision, cliché checks, and editorial scoring.

I built it with a Python/FastAPI backend and a browser interface.
The live demo is below; generated content still needs human review.

[Try it →](https://blog-agent-rho.vercel.app/)
· [Read the code →](https://github.com/Sujal-Kandi/Blog_Agent)

## AI Research Agent

**From a research question to a report you can inspect.**

A multi-stage workflow for planning searches, gathering sources,
drafting, critiquing, revising, and exporting cited PDF reports.

[Explore the project →](https://github.com/Sujal-Kandi/AI_RESEARCH_AGENT)
